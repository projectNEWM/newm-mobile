# Tech Stack

## Core Technologies
- **Language:** [Kotlin Multiplatform (KMP)](https://kotlinlang.org/docs/multiplatform.html)
- **UI Framework:** [Compose Multiplatform](https://www.jetbrains.com/lp/compose-multiplatform/)
- **Database:** [SQLDelight](https://cashapp.github.io/sqldelight/)
- **Serialization:** [Kotlin Serialization](https://kotlinlang.org/docs/serialization.html)

## Development Tools
- **Build System:** Gradle (Kotlin DSL)
- **Dependency Management:** Gradle Version Catalogs
- **Code Generation:** [KSP (Kotlin Symbol Processing)](https://kotlinlang.org/docs/ksp-overview.html)

## Quality Assurance
- **Linting & Formatting:** [Spotless](https://github.com/diffplug/spotless) (using ktfmt with Google Style and ktlint)
- **UI Testing:** [Paparazzi](https://github.com/cashapp/paparazzi) (for Compose UI snapshot testing)

## Platform Integration
- **Mobile:** Android & iOS
- **Desktop:** JVM
- **Web:** WasmJs
- **Services:** Firebase (Google Services)
